# Platform Size Presets

## Social Media Card Dimensions

| Platform | Format | Width | Height | Aspect Ratio | Notes |
|----------|--------|-------|--------|-------------|-------|
| Twitter/X | Landscape | 1200 | 675 | 16:9 | Most common share format |
| Twitter/X | Square | 1200 | 1200 | 1:1 | Gallery format |
| Instagram | Square | 1080 | 1080 | 1:1 | Standard post |
| Instagram | Portrait | 1080 | 1350 | 4:5 | Maximum canvas usage |
| Xiaohongshu | Portrait | 1080 | 1440 | 3:4 | Standard note image |
| Xiaohongshu | Square | 1080 | 1080 | 1:1 | Alternative |
| WeChat Moments | Story | 1080 | 1920 | 9:16 | Full-screen story |
| LinkedIn | Landscape | 1200 | 627 | ~16:9 | Article link preview |
| General | Universal | 1200 | 800 | 3:2 | Safe default |

## Layout Recommendations by Aspect Ratio

### Wide (16:9, 3:2)
- **Split Horizontal**: Left text, right decorative gradient
- **Editorial**: Large title dominating top, excerpt below
- **Minimal**: Clean title + metadata, centered
- **Centered**: All text centered with accent bar

### Square (1:1)
- **Centered**: Text centered with generous padding
- **Vertical Stack**: Header + title + excerpt + footer
- **Editorial**: Large title with tag badges
- **Minimal**: Title + metadata only

### Portrait (4:5, 3:4, 9:16)
- **Vertical Stack**: Full-height layout with header/footer bars
- **Centered**: Text centered with more vertical room for body
- **Editorial**: Large title + longer excerpt
